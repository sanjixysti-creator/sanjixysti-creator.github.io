Common questions

        

          

            Do these QR codes expire?
            
No. A QR Forever code is static: your link, text or Wi-Fi details are written into the picture itself. It does not go through our servers, so there is no trial, account or subscription that can switch it off. It keeps working for as long as whatever it points to still exists.

          

          

            Is it really free?
            
Yes. There is no sign up, no watermark, no limit on scans and no limit on downloads. You can use the codes for personal or business use, and you do not need to credit anyone.

          

          

            Do you store what I type, or track scans?
            
No. The code is made in your browser, and what you type is not sent anywhere. Nothing tracks scans, because a scan goes straight from the picture to the phone. Your settings are kept on this device only, and your entries only if you ask for that.

          

          

            Can I change where a code points later?
            
No, a static code is fixed once it is printed. If you might need to change the destination, point the code at a page you control and edit that page instead.

          

          

            Which error correction level should I choose?
            
Medium suits most things. Choose High if the code will be printed on something that may get scratched, dirty or partly covered. Choose Low for the simplest, least crowded code on a screen. Higher levels add repair data, which makes the code denser and harder to scan at a small size.

          

          

            PNG or SVG?
            
Use PNG for screens, slides, documents and messages. Use SVG for printing, signs and anything that has to be scaled up, because it stays sharp at any size.

          

          

            How big should I print it?
            
Make it at least 2 cm (about 0.8 inch) wide for something held in the hand. As a rule of thumb, a code scans from about ten times its width away, so a 10 cm code works from around a metre. Keep the white border and print it dark on light.

          

          

            Why will my code not scan?
            
Check four things. Keep the white border around it. Use a dark code on a light background with plenty of contrast. Print it large enough for the distance it will be scanned from. Shorten the text if you can, because less text makes a simpler code with bigger squares.
